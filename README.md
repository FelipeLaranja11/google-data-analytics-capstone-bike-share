🚴‍♂️ Cyclistic Bike Share Analysis
Turning Data into Strategic Insights for Marketing Team

📌 About the Project
This project is part of the Google Data Analytics Capstone, aimed at analyzing usage patterns of the Cyclistic Bike-Share program to identify strategies that can encourage casual users to become annual members.

Throughout this journey, I encountered technical challenges and explored various tools to ensure the analysis was conducted in the best possible way.

🛠 Tools Used
🔹 R (Posit Cloud) – Data cleaning and initial analysis (limited by memory).
🔹 Power Query – Data extraction and transformation.
🔹 Excel – Data manipulation and analysis
🔹 ChatGPT & Copilot (AI) – Assisted in query creation and analysis refinement.
🔹 Tableau – Dashboard creation and interactive visualizations.
🔹 Gamma (AI) – Generated a draft for the final presentation.
🔹 PowerPoint – Finalizing and structuring the presentation.

💡 Key Learnings and Challenges
🔹 Posit Cloud Limitations: Struggled with large files, requiring filtering to prevent crashes.
🔹 Use of AI in the Process: ChatGPT and Copilot played a pivotal role in optimizing queries and data processing.
🔹 Data Visualization: Tableau made it easier to identify patterns and derive strategic insights.
🔹 Storytelling Optimization: Gamma helped shape a compelling visual narrative for the final report.

📊 Key Findings
✅ Annual users account for 64% of rides, indicating strong retention.
✅ Casual users prefer weekends, while members show more consistent usage.
✅ High demand in summer and fall, suggesting seasonal opportunities for conversion.
✅ Popular stations are in central, high-traffic areas, essential for marketing strategies.
